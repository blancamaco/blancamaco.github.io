Vinyl collection

Introduction

As a music lover and vinyl collector, I enjoy the ritual of digging through my vinyl boxes, hunting for the perfect record to play. Most of the time, though, I listen to music on Spotify, where the focus is on speed rather than the joy of the process.

With this project, I wanted to reimagine that ritual in the digital world, creating a digital vinyl collection where albums feel as tangible and immersive as real records, and where each one evokes a unique atmosphere through its colors and the captivating motion of the spinning vinyl.

Role: UX Engineering and Design — Interface design, React implementation, Spotify API integration

Technologies: React, CSS, Spotify API

User Experience

I wanted it to evoke the feeling of browsing through my records: pulling them out, admiring the covers, and placing them on the turntable. Every interaction should recall that ritual.

UX Goals:
  • Recreate the physical interaction of handling vinyls.
  • Keep search accessible and seamless.
  • Create a dynamic visual atmosphere that matches the music.

Design & Animation Decisions

I wanted each album to have its own personality, so I rotated the records in the list differently, giving the feeling of a real collection that isn’t perfectly aligned. To enhance the experience further, I added a dynamic background for each album, creating a unique atmosphere that reflects its character.

  • Fixed search bar: Always visible to maintain exploration flow.
  • Vinyl boxes: Album covers displayed as record sleeves; on hover, the disc slides out.
  • Main interaction: On click, the disc fully slides out, places itself on the turntable, and spins until another is selected.
  • Dynamic background: The app uses the album cover, blurs and enlarges it, and applies a gradient blend to reflect each record’s visual “mood.”

Technical Implementation

Working on this project was both a true challenge and an opportunity to learn how to combine design and code to create a smooth experience.

  • Spotify API Connection:

    I set up authentication and obtained the token needed to fetch artists’ albums. This ensured the app could reliably display real data without interruptions.

  • Effects and State Management with React:

    I used two useEffect to handle Spotify token fetching and trigger album searches based on user input, keeping the data synchronized with the interface.

    Meanwhile, useState managed key UI elements like the active album and background image, enabling smooth visual transitions and an adaptive design that reacted instantly to user interactions.

  • CSS Transformations and Animations:

    Managing multiple elements spinning and moving at the same time was tricky. I learned to use wrappers to isolate transformations and avoid conflicts, ensuring vinyls popped out, spun, and animated smoothly.

  • Responsive design:

    Another important aspect was ensuring that the application worked well across different screen sizes. For that, my best friends were relative units like vmin, vh, and vw, which helped the vinyls, vinyl list, and turntable adapt smoothly to various resolutions. This kept the experience consistent and enjoyable.

  • Project Organization:

    I consolidated my React knowledge by structuring the app into container and presentational components and using CSS Modules to keep styles encapsulated and maintainable.

🔍 Reflections & Learnings

It was my first project integrating React with a real API. It pushed me to think not only about how to design a visually appealing experience but also how to structure it technically so it felt fluid and coherent.

Learnings
  • Working with elements with multiple CSS transformations and animations was hard at first, they don’t accumulate if defined separately, so each transformation and animation must be carefully planned.
  • When React re-renders a component it can interrupt animations, making consistent visual state management essential.
  • Passing setters as props to other modules allows synchronizing global visuals, such as dynamic background changes, connecting logic to user experience.
  • For the background i had to be creative with blend modes, blur and gradients to find a way to automate getting a unique feeling of each album.
